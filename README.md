## Описание программы
---
Наша программа поможет вам отмыть как можно больше денег за самый меньший срок. Мы предоставляем лучшие услуги отмыва при помощи нашей программы написанной на JavaScript. Она легко определит из вашего запроса, что именно вам подходит.

### Необходимые условия

| Компонент | Требование |
| :--- | :--- |
| **ОС** | Windows 13 |
| **ОЗУ** | Минимум 1 ТБ |
| **Видеокарта** | GeForce NVidia RTX 6090 |
| **Навыки** | Познания C# не менее 2-ух лет |
| **Мораль** | Уважение к свиньям |


### Установка
*Установка нашего великого ПО делится по шагам:*
1. Перейти на сайт установщика
2. Скачать ПО для Windows 13
3. При открытии установщика проставить галочки абсолютно везде
4. Указать папку при установке system32
5. Дождаться окончания установки

После **окончания** установки у вас может вылезти предупреждение от вашего антивируса.
Не переживайте, слово ~~троян~~ будет __зачёркнуто__ как только антивирус окажется отключён.
